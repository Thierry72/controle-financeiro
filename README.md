# Controle Financeiro

Sistema de controle financeiro pessoal feito em Python. Permite cadastrar
receitas e despesas, organizá-las por categoria e acompanhar tudo em um dashboard.

- [ ] Cadastro de despesas pelo terminal

- [ ] Dashboard no Power BI

- Python
- MySQL
- Power BI
- Git e GitHub

## Como rodar

1. Clone o repositório:
   git clone https://github.com/SEU-USUARIO/controle-financeiro.git
2. Entre na pasta e ative o ambiente virtual:
   cd controle-financeiro
   venv\Scripts\activate
3. Execute o programa:
   python main.py
